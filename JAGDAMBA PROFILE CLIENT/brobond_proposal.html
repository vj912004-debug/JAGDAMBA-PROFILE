1. Project Overview

This proposal outlines the development of a custom ERP system designed to digitize and streamline field sales operations, automate order workflows, track employee movement, and provide real-time inventory visibility for management.

The system will allow sales executives to create orders during field visits, track attendance through GPS and face verification, capture store audit images, and provide administrators with real-time dashboards and analytics.

2. Scope of Development

2.1 User & Role Management

  • Secure login system
  • Role-based access control
  • Admin, Delivery Staff roles
  • User management & permissions

2.2 Smart Attendance System

  • Face recognition punch in/out
  • Selfie capture during attendance
  • GPS coordinate tracking
  • Timestamp recording
  • Admin dashboard logs

2.3 Beat Planning System

  • Admin route assignment
  • Retailer visit lists
  • Route planning & monitoring
  • Field staff optimization

2.4 Live GPS Tracking

  • Real-time field employee tracking
  • Route path visualization
  • Distance travelled monitoring
  • Timestamped visit history
  • Live multi-employee map

2.5 Shelf Audit & Images

  • Capture store shelf images
  • GPS tagging with timestamp
  • Image verification by admin
  • Store compliance tracking

2.6 Dashboard & Analytics

  • Employee productivity monitoring
  • Sales trend analysis
  • Live operation overview
  • Automated reporting
