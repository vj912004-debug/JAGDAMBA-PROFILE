# BroBond India ERP - Field Sales Automation

## Project Overview
A custom ERP system designed for **Shree Nakoda Beverages Pvt. Ltd.** to digitize field sales operations, automate order workflows, and provide real-time visibility into employee movement and inventory.

## Key Features
- **Smart Attendance**: Face recognition and GPS-validated punch-in/out.
- **Beat Planning**: Admin-assigned daily routes and sequence optimization.
- **Live GPS Tracking**: Real-time tracking of employees on a live map with distance monitoring.
- **Shelf Audit**: GPS-tagged image capture for retail store compliance.
- **Admin Dashboard**: Comprehensive productivity monitoring and sales analytics.

## Technology Stack
- **Frontend**: React.js, TypeScript, Vite, Tailwind CSS.
- **Backend**: Node.js, Express.js, PostgreSQL, Prisma ORM.
- **Services**: AWS Rekognition (AI), Google Maps API, AWS S3.
